# Bioinfo_scripts
Repositório para armazenar meus scripts em python para análise de dados brutos de sequenciamento genômico, e emissão de relatórios finais sobre as mutações genéticas encontradas. Todos os scripts são gerenciados por um arquivo orquestrador que funciona como main.

A integridade dos arquivos fastQ é inicialmente avaliada por meio de validação hash MD5 e verificação do pareamento equitativo entre arquivos R1 e R2, a análise de qualidade é realizada pré e pós trimágem com o uso da ferramenta fastCQ. A trimagem de adaptadores e filtragem de reads com métricas de qualidade insatisfatórias, se dá por meio do uso da ferramenta Trimmomatic. As reads filtradas são alinhadas contra o genoma de referência (GRCh38) por meio do uso do algoritmo de alinhamento BWA-MEM, os arquivos de alinhamento: Sequence Alignment/Map (SAM), serão então convertidos para Binary Alignment/Map (BAM) utilizando-se a suite Samtools, a profundidade e cobertura de sequenciamento é avaliada utilizando a ferramenta Mosdepth.
A chamada de variantes somáticas é realizada utilizando o módulo Mutect2 da plataforma Genome Analysis Toolkit (GATK), em sequencia as variantes identificadas são filtradas, com o uso do algoritmo FilterMutectCalls, gerando o arquivo Variant Calling Format (VCF). A anotação de variantes se dá pelo uso da ferramenta ANNOVAR, consultando informações dos bancos de dados (RefSeq, ClinVar, e COSMIC). A predição do impacto oncogênico é realizada por meio da ferramenta CancerVar, consultando-se: bancos de evidências clínicas/oncológicas (ClinVar, COSMIC, ICGC), bancos de frequência populacional (gnomAD) e algoritmos de predição de impacto funcional  in silico (CADD, SIFT, MutationTaster, FATHMM, FATHMKL, MetaSVM, MetaLR, PROVEAN, MutationAssessor, VEST3 e DANN).

Ao final os dados obtidos são tratados utilizando a biblioteca pandas para elaboração de relatórios contendo os resultados das análises e das consultas feitas aos bancos de dados para que estes possam ser utilizados para o diagnóstico clinico de doenças oncológicas de cunho somático.
